# Medusa RBAC 0.0.2

This patch improves native Medusa Admin authorization and package release reliability. Medusa 2.22.2 remains the compatibility baseline.

- Honor native Superuser authority across Admin operations and permission views while preserving ordinary role and contextual permission boundaries.
- Support reviewed native Admin detail, modal, inventory, customer address and layout projections. Preserve absent query fields and enforce capabilities before self-profile effects.
- Normalize native sales channel rule lookup and validate variant fields against the returned entity.
- Centralize package preparation, archive checks, provenance verification and npm trusted publishing in the shared actions workflow, pinned to a reviewed immutable commit.
- Keep local builds and release builds on the same standard esbuild command, with identical public ESM bundles and shared ESM/CommonJS client checks.

## Release verification

The prepared package contains the compiled server, Admin, types and client exports. Verify the GitHub archive with SHA256SUMS and its provenance bundle. Publication uses that exact archive, then verifies npm registry integrity and downloaded bytes. GitHub preparation, GitHub release publication and npm publication are separate results; successful npm verification is required before adopting the shared workflow in other plugins.

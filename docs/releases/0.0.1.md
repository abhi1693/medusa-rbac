# Medusa RBAC 0.0.1

The first release provides configurable access control and native Admin management for Medusa 2.22.2 or newer. Validation and native route/field snapshots target Medusa 2.22.2.

- Define permissions and ordinary roles in application code, or create editable roles in Admin. Superuser is the only built-in role.
- Combine role grants with contextual allow/deny rules, trusted permission context and server-side authorization.
- Manage roles, accounts, invitations and access history through Medusa UI screens, native user-detail widgets and searchable account selection.
- Use native user editing, password-reset links and guarded deletion, preserving self-deletion and last-Superuser protections.
- Assign roles during invitation acceptance before first login, with workflow compensation and live access revocation.
- Extend native user/customer identity handling with custom actor providers and a storefront access client.
- Synchronize code-managed roles with stable keys, versions and transactional audit records.

The release archive includes compiled server, Admin, type and storefront client exports. Verify it against `SHA256SUMS` before installation. See the [README](https://github.com/abhi1693/medusa-rbac#install) for configuration, database setup and administrator bootstrap.
